A full-stack public grievance & constituency management platform that connects citizens, elected MLAs, constituency offices and municipal departments, all in one place.

View on GitHub Run it locally

How a complaint travels

Every grievance gets a unique reference like JS-2026-XXXXXX and a live status timeline.

Submitted→ Verified→ Assigned→ In Progress→ Resolved→ Closed

Five connected apps

One platform, five roles.

1. Citizen App

  • Mobile OTP and email login
  • Map pin-drop with GPS (Leaflet / OpenStreetMap)
  • Duplicate detection within 200 m
  • Evidence upload: photo, video, PDF
  • Reopen complaints and rate the resolution

2. MLA Dashboard

  • Live KPIs: resolution rate, SLA compliance, avg. time, satisfaction
  • Geospatial map with ward overlays
  • One-click assignment to departments
  • Filterable reports with CSV export

3. Field Officer Desk

  • Department-scoped task backlog
  • Progress updates through to Resolved
  • Before / after photo proof
  • Comment thread with citizens and MLA office

4. Super Admin Console

  • Role-based access for 5 user roles
  • Configurable SLA targets (24h / 48h / 120h / 240h)
  • Tamper-evident audit trail
  • Departments, categories and boundaries

5. Transparency Portal

  • Public open-data dashboard
  • Resolution rates and department speed
  • No citizen personal data exposed

Run it locally

Needs Node.js installed. Opens the frontend on port 3000 and the API on port 5000.

git clone https://github.com/Dhaneshwar11/jansankalp.git
cd jansankalp
npm install
npm run dev
